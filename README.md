# Advisory+ — Marketing Assets

Asset visivi per le campagne marketing di Advisory+ (marchio commerciale di Studio Solutions S.r.l. — RUI Sez. A n. A000669271).

## Struttura

- `cover-blog/` — immagini di copertina degli articoli del blog "THE ADVISOR"
- `linkedin/` — grafiche per post LinkedIn (pagina aziendale + profili soci)
- `instagram/` — grafiche per post Instagram (@advisoryplus_)
- `facebook/` — grafiche per post Facebook (riusi IG + adattamenti dedicati)
- `team/` — foto soci/dipendenti per pagina "Chi siamo" e citazioni

## Convenzione naming

```
[YYYY-MM-DD]_[canale]_[tema]_[variante].[ext]
```

Esempi:
- `cover-blog/2026-05-12_cover_ltc_pillar_og.jpg`
- `linkedin/2026-05-13_linkedin_carosello_ltc.pdf`
- `instagram/2026-05-30_instagram_numero_inflazione.jpg`

## Uso

Repository pubblico. Le immagini sono linkabili via URL `raw.githubusercontent.com` per scheduler social (es. Buffer):

```
https://raw.githubusercontent.com/DanieleSimonini/adv-marketing/main/cover-blog/[filename]
```
